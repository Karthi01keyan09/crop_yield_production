ℹ️ About CropSense AI

An end-to-end machine learning system for Indian agriculture yield prediction.

🤖

ML Models

Random Forest regressor predicts yield (kg/ha) with low MAE. XGBoost classifier recommends the best crop with high accuracy.

Random Forest XGBoost scikit-learn
🌾

Dataset

Synthetic dataset inspired by Indian agriculture patterns. Covers 10 major crops, 10 states, 3 seasons, 7 soil types across 5,000 records.

Kaggle-style Indian Agri 5,000 rows
🔧

Tech Stack

Flask REST API backend with CORS. Vanilla HTML/CSS/JS frontend. Chart.js for rich visualisations. Auto model training on first run.

Flask Python 3.10+ Chart.js 4
📊

Features

Yield prediction · Best crop recommendation · Fertilizer NPK plan · Irrigation strategy · Dataset insights dashboard.
